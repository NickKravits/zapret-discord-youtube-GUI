# Изменения

## 1.0.0

Первый релиз.

- Выбор и запуск стратегий из zapret-discord-youtube в один клик
- Автозапуск обхода через службу Windows (совместима с `service.bat`) или systemd
- Автозапуск приложения при входе в систему, сворачивание в трей
- Подключение Comss DNS: обычный DNS и DNS-over-HTTPS (Windows 11)
- Тест стратегий: проверки HTTP/1.1, TLS 1.2, TLS 1.3 и ping, выбор лучшей стратегии
- Редактор списков доменов и IP с быстрым добавлением и автоопределением типа
- Журнал работы winws/nfqws
- Game Filter, режимы IPSet, обновление списка IPSet и файлов zapret, диагностика
- Экспериментальная поддержка Linux (nfqws + nftables)
